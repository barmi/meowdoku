# meowdoku

고양이 퀸즈(Queens / Star Battle) 퍼즐 웹게임. 모바일 게임 스크린샷을 기준으로 화면 구성·색·치수를
최대한 비슷하게 옮겼다. 그림은 원본 이미지를 쓰지 않고 전부 SVG 로 새로 그렸다.

## 규칙

- **색깔당 고양이 1마리** — 색깔 영역마다 고양이가 딱 한 마리
- **행과 열마다 고양이 1마리**
- **고양이 인접 불가** — 대각선을 포함해 두 고양이가 맞닿을 수 없다

모든 퍼즐은 해가 하나뿐이고, 찍지 않고 논리만으로 풀린다(생성할 때 논리 엔진으로 확인).

### 오픈(처음부터 놓인 고양이)

원본 게임이 정답 하나를 열어 두는 건 문제에 경우의 수(해가 여러 개)가 있어서 부득이 연 것이다.
그래서 여기서는 **오픈 없이 해가 여러 개인 판에만 1마리**를 열고, 오픈 없이도 해가 하나면 열지 않는다.
생성기는 영역 경계를 고쳐서라도 오픈 없이 해가 하나인 판을 만들기 때문에 레벨은 보통 빈 판으로
시작한다. 스크린샷 판(701·702)도 계산해 보니 오픈 없이 해가 하나라서 열지 않는다 (#2).

## 조작

| 동작 | 결과 |
| --- | --- |
| 탭 | X 토글 — 빈 칸 → X, X → 지우기 (#7) |
| 더블탭(더블클릭) | 고양이 놓기 — 정답이면 고정·점수, 틀리면 물고기 1마리를 잃고 화면이 지진처럼 흔들리며 그 칸에 빨간 X 가 남는다 (지워지지 않음, #8) |
| 누른 채로 쓸기 | 지나간 빈 칸에 X (X 에서 시작하면 지우개) |
| 규칙 카드를 옆으로 밀기 | 마커 도구 — 아래 참고 (#10) |
| 키보드 | 방향키 이동, Space/Enter X 토글, `X` X 토글, `C` 고양이, Backspace X 지우기 |

물고기(목숨) 3마리를 다 잃으면 게임 오버 — 판마다 한 번 "이어하기"로 다시 채울 수 있다.

### 마커 (#10)

규칙 카드(색깔당·행과 열·인접 불가)를 좌우로 밀거나 아래 점을 누르면 마커 도구가 나온다.

- **세모·동그라미·네모**: 고르면 마커 모드(판 둘레 점선). 빈 칸을 누르면 그 마커, 같은 마커를 다시 누르면 지움,
  누른 채 쓸면 여러 칸에. **지우개**로 지우고 **전체 지우기**로 한 번에 지운다
- 고른 도구를 다시 누르거나 규칙 쪽으로 넘기면 마커 모드가 끝나고 탭·더블탭이 원래대로(X·고양이)
- 생각 정리용이라 정답 판정·힌트·통계와 상관없다. 빈 칸에만 보이고(X·고양이가 놓이면 가려짐),
  판 진행과 함께 저장·기기 간 이어하기가 되며, 판을 처음부터 다시 하면 지워진다

### 아이템

| 아이템 | 효과 |
| --- | --- |
| 🐱 고양이 부르기 | 후보가 가장 적은 영역의 정답 칸에 고양이를 놓아 준다 |
| 💡 힌트 전구 | 틀린 X 가 있으면 먼저 지워 주고, 없으면 다음 한 수를 이유와 함께 보여 주고 적용한다 |
| 🐭 쥐 풀기 | 쥐가 한 줄(고양이가 아직 없는 줄 우선)을 달리며 고양이가 없는 칸을 모두 X 로 |

개수가 0 이면 원본처럼 초록 ▶ 배지가 뜬다. 광고는 없고 누르면 무료로 1개 받는다.
레벨을 깨면 아이템을 하나씩 돌아가며 준다.

### 하루 통계 (#5)

홈의 "하루 통계 ›" (또는 `/?stats`) 에서 날짜별로 본다. ‹ › 로 지난 날(최근 90일)도 넘겨 본다.

- 요약: 클리어한 판(플레이한 판 대비 %), 플레이 시간, 얻은 점수·맞힌 고양이, 연속 플레이 일수
- 시간대별 플레이 (0~23시 막대 — 누르면 값, 화면 읽기용 표 포함)
- 기록: 평균·가장 빠른 클리어 시간, 최고 점수 판, 실수 없이 클리어한 판 수
- 실수와 아이템: 틀린 고양이(잃은 물고기), 게임 오버, 아이템별 사용 횟수
- 판 크기별 클리어, 그날 클리어한 판 목록 (시각·판·크기·난이도·실수·점수·시간)

"플레이한 판"은 한 번이라도 손댄 판, 플레이 시간은 판을 만진 뒤 화면을 보고 있던 시간
(팝업이 떠 있거나 앱이 가려진 시간은 뺀다)이다. 기록은 `localStorage` 의 저장 데이터에 날짜별로 쌓인다.

### 점수

- 고양이를 맞히면 `100 + 속도 보너스(최대 60) + 연속 정답 20×콤보`
- 클리어 보너스: 남은 물고기 ×150, 실수 없음 +300, 시간 보너스 `(칸 수×3초 − 걸린 시간)×2`

원본 앱의 점수 공식은 알 수 없어서 새로 정했다.

## 실행 환경

- Node.js 22.12 이상 (Node 26 에서 확인), npm
- Vite 8 + TypeScript 7 (프레임워크 없는 vanilla DOM), 테스트는 Vitest

```bash
npm install

npm run dev      # 개발 서버 http://localhost:5173 (0.0.0.0 로 열림 — 같은 네트워크의 폰에서 Network 주소로 접속)
npm test         # 퍼즐 생성기·풀이기·게임 규칙 테스트
npm run build    # 타입 검사 + dist/ 에 정적 빌드
npm run serve    # 빌드 후 http://localhost:4173 로 서빙 (0.0.0.0)
```

`dist/` 는 상대 경로(`base: './'`)로 빌드되므로 아무 정적 서버로 서빙해도 된다
(단, 정적 서버에는 아래 저장 API 가 없어서 기기별 저장으로만 동작한다).

```bash
npm run build && python3 -m http.server 8080 -d dist
```

폰(iPhone Safari)에서 열고 "홈 화면에 추가" 하면 주소창 없이 앱처럼 전체 화면으로 뜬다
(`public/manifest.webmanifest`, apple-touch-icon).

갖고 있으면 서버에도 저장해서 **어느 기기에서 열어도 이어서 한다** (아래).

## 기기 사이 이어하기 (#6)

`npm run dev`·`npm run serve` 서버에는 게임 상태 저장 API(`/api/state`)가 붙어 있다
(`server/stateStore.ts`, Vite 플러그인). 상태는 서버 디스크의 JSON 파일 하나에 통째로 저장된다.

| 항목 | 값 |
| --- | --- |
| 저장 파일 | `data/state.json` (git 제외), 환경변수 `MEOWDOKU_STATE=/경로/state.json` 으로 변경 |
| `GET /api/state` | `{ rev, updatedAt, data }` |
| `PUT /api/state` | `{ baseRev, data }` — baseRev 가 서버 rev 와 같을 때만 저장(rev+1), 아니면 409 + 최신 상태 |

- 화면을 실시간으로 맞추지는 않는다. **액션마다 결과를 올리고**, 열 때·화면으로 돌아올 때(focus/visible)·
  네트워크가 돌아올 때 최신 상태를 받는다. 흐른 시간만 바뀐 건 올리지 않고, 화면을 떠날 때 올린다.
- 판마다 `gameId` 를 붙이고, 끝낸 판은 `finished` 목록에 남긴다. 다른 기기가 먼저 저장했으면:
  - 붙잡고 있던 판이 **다른 곳에서 이미 끝났거나 다른 판으로 바뀌었으면 → 경고 후 최신 상태로 새로 로딩**
  - 같은 판을 다른 곳에서 더 진행했으면 → 그 진행으로 새로 로딩하고 알림 (늦은 기기의 수는 버림)
  - 다른 곳이 이 판을 건드리지 않았으면(시간·통계만 바뀜) → 마지막으로 맞춘 상태를 기준으로 3-way
    병합해서 이 기기의 수를 살려 저장 (`src/game/merge.ts`)
- 한 번도 서버와 맞춰 본 적 없는 기기는 서버 상태를 그대로 받는다. 서버가 비어 있으면 처음 접속한
  기기의 상태가 공유 상태가 된다.
- 서버에 닿지 않으면 이 기기에만 저장하고, 다시 연결되면 맞춘다. 설정 화면에 저장 상태가 보인다.
- 인증이 없으니 믿을 수 있는 네트워크(LAN·Tailscale)에서만 연다. 처음부터 다시 하려면 서버를 끄고
  `data/state.json` 을 지우거나, 설정의 "기록 초기화"(서버의 공유 상태도 초기화된다).

## 레벨(판 번호)과 난이도

화면의 "레벨 N" 은 원본 화면 표기를 그대로 따른 **판 번호**다 (#4).

- 판 번호는 1, 2, 3 … 순서대로 진행하고, 같은 번호면 언제나 같은 판이다 (번호가 시드).
- 판 크기와 난이도는 번호와 상관없이 **랜덤** — 번호가 커진다고 어려워지지 않는다.
  - 크기: 5×5 6% · 6×6 14% · 7×7 22% · 8×8 30% · 9×9 18% · 10×10 10%
  - 목표 난이도: 쉬움 30% · 보통 40% · 어려움 30% (풀이에 허용하는 기법 단계로 조절)
- 홈·레벨 선택·클리어 화면에는 실제로 풀 때 필요한 기법으로 매긴 난이도(★)를 보여 준다.
- 701·702 는 스크린샷 판 그대로.

### 퍼즐 생성

1. 규칙을 지키는 고양이 배치(정답)를 먼저 뽑는다.
2. 고양이 칸을 씨앗으로 영역을 무작위로 키운다 — 매 걸음 "영역"을 먼저 골라서 한 영역만 비대해지지 않게
   하고, 일부 영역은 곧게 뻗게 해서 원본 같은 띠 모양이 나오게 한다.
3. 해가 여러 개면, 다른 해에만 있는 고양이 칸을 이웃 영역으로 넘겨 그 해를 깨뜨린다. 정답 칸은
   건드리지 않으므로 정답은 계속 유효하다. 오픈 없이 유일해가 될 때까지 반복하고, 막히면 판을 새로
   만든다(1마리 오픈은 그래도 못 만들 때만 쓰는 안전장치).
4. 논리 엔진(한 칸 남음 → 한 줄에 몰림 → 두면 다른 줄이 비는 칸 → k개 영역/k개 줄 → 가정 후 모순)으로
   끝까지 풀리는지 확인하고, 판 크기에 맞는 난이도만 통과시킨다.

8×8 한 판 생성에 수 ms 정도라 미리 만들어 두지 않고 그때그때 만든다.

## 원본과 다른 점

- 광고 없음 — 광고 자리는 비우고, ▶ 배지는 무료 충전으로 동작
- 상단 고양이 바는 색 순서 고정 (원본은 순서가 바뀌어 보이는 경우가 있음)
- 원본에 없는 홈 화면·설정·게임 방법·레벨 선택·자동 X 옵션을 같은 톤으로 추가
- 쥐 아이템의 원래 효과는 알 수 없어 "한 줄 정리"로 정함
